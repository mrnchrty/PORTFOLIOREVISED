# Local icon assets

The SVGs in this directory are bundled locally so the portfolio does not depend on a third-party icon CDN.

- `social-*.svg`, `hobby-*.svg`, `skill-*.svg`, and `contact-*.svg` use Bootstrap Icons (MIT), locally tinted for readability. See `licenses/LICENSE-BOOTSTRAP-ICONS.txt`.
  - `skill-*.svg` are the Core Skills marks (lightbulb, flow diagram, speech bubbles, two people, artist palette, pencil).
  - `section-*.svg` are the section-heading marks that replaced the numeric badges (mortarboard, stars, code, briefcase, award, person badge), tinted to the accent colour.
  - `vscode.svg` is the Visual Studio Code mark from Devicon (MIT), alongside `canva.svg`, `cplusplus.svg`, and `mysql.svg` which already came from that set. Brand colours are kept to match the other tech-stack chips.
  - `contact-*.svg` are the resume contact marks: map pin, telephone, envelope, GitHub, and LinkedIn. All five are tinted to the theme accent `#8741a3` and share the 16x16 Bootstrap viewBox, so the round social marks match the line-art glyphs in colour and optical weight. The untinted `github.svg` / `social-github.svg` and `social-linkedin.svg` marks are still used elsewhere in the project and were left untouched.
- `facebook.svg`, `instagram.svg`, `linkedin.svg`, `github.svg`, `git.svg`, `x.svg`, `tiktok.svg`, `pinterest.svg`, `roblox.svg`, `html5.svg`, `css.svg`, `javascript.svg`, `postgresql.svg`, and `python.svg` use Simple Icons marks (CC0-1.0). See `licenses/LICENSE-SIMPLE-ICONS.txt`.
- `canva.svg`, `cplusplus.svg`, and `mysql.svg` use Devicon marks (MIT). See `licenses/LICENSE-DEVICON.txt`.
- `microsoft-word.svg`, `microsoft-powerpoint.svg`, and `microsoft-excel.svg` use Material Design Icons marks, with application-brand colors (Apache-2.0). See `licenses/LICENSE-MATERIAL-DESIGN-ICONS.txt`.

The page uses a local Roblox mark; the other requested game titles are text-first labels rather than guessed or scraped artwork. Product and platform names/logos are used only for identification. Trademarks belong to their respective owners.
